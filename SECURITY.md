# Política de seguridad

## Reportar una vulnerabilidad

Envía el reporte mediante [GitHub Security Advisories](https://github.com/DebianS4/DC-LINUXOS/security/advisories/new), que permite comunicar el problema de forma privada a quienes mantienen el repositorio. Incluye la versión o release afectada, los pasos para reproducirlo y el impacto observado.

No publiques claves, contraseñas, datos personales ni detalles que permitan explotar el problema en un issue o pull request público. No se promete un plazo específico de respuesta; el equipo revisará los reportes recibidos por el canal privado.
