# DC-LINUX — Entregables

## Landing visual azul y negra
- [x] La página presenta DC-LINUX como un sistema operativo basado en Linux con una estética futurista inspirada en el escritorio compartido.
- [x] La identidad visual usa tonos azul, negro y acentos rojos, con contraste suficiente, tipografía técnica y composición responsive.
- [x] La página tiene una navegación clara entre las secciones principales y una navegación móvil desplegable.

## Contenido del sistema
- [x] La sección introductoria explica que DC-LINUX es una edición Live ligera basada en Debian 13 (Trixie) y XFCE.
- [x] Se comunican las capacidades verificadas del repositorio: amd64, BIOS/UEFI, firmware amplio, NetworkManager, Firefox ESR e instalador Live de Debian.
- [x] Las características principales están presentadas como módulos de lectura rápida.

## Recursos visuales y entorno
- [x] El hero usa una imagen original generada para el proyecto con composición azul/negra y espacio para el mensaje de marca.
- [x] El bloque editorial usa una segunda imagen original generada para reforzar la identidad de núcleo y código abierto.
- [x] La galería reutiliza la captura existente del repositorio y muestra una vista adicional del lenguaje visual.

## Accesibilidad y entrega
- [x] La estructura usa HTML semántico, textos alternativos, foco visible, enlaces descriptivos y soporte para `prefers-reduced-motion`.
- [x] El manifest de rutas declara la página raíz en `/manus-routes.json`.
- [x] La experiencia está preparada para previsualización en el proyecto Webdev y para integrarse con el repositorio de DC-LINUX.
